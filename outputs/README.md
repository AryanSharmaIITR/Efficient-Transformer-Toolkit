# Outputs

This directory stores all auto-generated runtime artifacts from training,
evaluation, and benchmarking runs.

## Directory Structure

```
outputs/
  models/       # Model checkpoints (.pt, .bin, .safetensors)
  logs/         # TensorBoard event files and text logs
  plots/        # Generated matplotlib/seaborn figures (.png, .pdf)
  reports/      # Benchmark CSVs, JSONs, and HTML reports
  README.md
```

## Gitignore Policy

The entire `outputs/` directory is **auto-generated** and gitignored
(`outputs/` in the project's `.gitignore`) — nothing under it is committed
to version control, including this subdirectory layout. The scripts that
write here (`run_train.py`, `run_benchmark.py`, `run_eval.py`,
`run_quantize.py`) create whatever subdirectories they need via
`Path.mkdir(parents=True, exist_ok=True)`, so a fresh clone doesn't need
the layout to pre-exist.

Figures or results worth keeping for reference (e.g. for the README) should
be copied out to `assets/`, which **is** tracked in git, rather than
committing anything from `outputs/` directly.

## What Goes Where

| Directory      | Contents                                                       | Generated By               |
|----------------|----------------------------------------------------------------|----------------------------|
| `models/`      | `*.pt`, `*.bin` checkpoint files                               | `run_train.py`, `Trainer`  |
| `logs/`        | TensorBoard `events.out.tfevents.*`, `*.log`                   | `run_train.py`, TensorBoard|
| `plots/`       | Attention heatmaps, benchmark bar charts, loss curves          | `run_benchmark.py`, notebooks|
| `reports/`     | `benchmark_results.csv`, `*.json`, `*.html`                    | `run_benchmark.py`         |

## Cleanup

To remove all generated files but keep the directory structure:

```bash
# Linux / macOS
find outputs -type f ! -name '.gitkeep' -delete

# Windows (PowerShell)
Get-ChildItem -Path outputs -Recurse -File | Where-Object { $_.Name -ne '.gitkeep' } | Remove-Item
```
